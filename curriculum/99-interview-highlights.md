## 项目一：txc-1.0 全栈开发框架

### 亮点候选（挑 3 个，各配证据）

1. **服务脚手架**：设计了分层中间件体系（错误兜底/日志/requestId/限流），统一错误码规范，服务 P95 排障时间从 X 降到 Y。
   追问预案：洋葱模型执行顺序、优雅退出两步、限流算法选择。
2. **构建优化**：定位慢构建瓶颈，通过代码分割 + 持久化缓存把二次构建从 Xs 降到 Ys，首包从 X KB 降到 Y KB（附 analyzer 图）。
   追问预案：loader/plugin 区别、tree shaking 失效排查、HMR 原理。
3. **发包体系**：changesets 自动化版本管理，包双格式输出（ESM/CJS），peerDependencies 解决框架双实例问题。
   追问预案：三类依赖区别、semver 判断、回滚一次错误发布的步骤。
4. **交付链**：多阶段构建镜像从 GB 级降到 X MB，CI 全绿流水线 + readiness/liveness 探针 + 一次「坏版本 60 秒回滚」演练。
   追问预案：镜像瘦身高手、滚动 vs 金丝雀、readiness 与 liveness 区别。

### 高频面试题清单

- Koa 洋葱模型与 Express 差异；一个请求错误在洋葱里怎么传播？
- Webpack 构建流程；为什么 tree shaking 只对 ESM 生效？
- 聚合根怎么划分？领域服务与应用服务边界？
- Vue3 Proxy 相比 defineProperty 解决了什么？动态组件与异步组件区别？
- monorepo 怎么管理包版本一致性？
- 生产一次发布到回滚的完整流程与你的角色。

## 项目二：txc-2.0 Agent 开发框架

### 亮点候选

1. **Agent Loop**：手写含五种终止路径的循环（MAX_STEPS/预算/超时/finish/审批），工具错误作为 Observation 喂回模型提升自愈率。
   追问预案：白板画状态机；为什么工具失败不抛异常。
2. **LLM Gateway**：Provider 抽象 + 指数退避重试 + 降级链 + usage 计量，主模型全挂时服务可用（附故障演练记录）。
   追问预案：哪些错误可重试？降级如何不打污染评测数据？
3. **流式与追踪**：SSE 事件协议 + Last-Event-ID 断点续传 + 全链路 Trace 回放，断网 10 秒重连无重复无丢失（附测试）。
   追问预案：续传位点存哪？write after end 怎么防？
4. **RAG 与引用**：五步管线 + 编号引用强制 + 引用核对护栏，回答 100% 可回溯（附命中率数据）。
   追问预案：切分策略；Top-K 预算；无据拒答怎么保证。
5. **质量门禁**：50 条五类评测集进 CI，Prompt 劣化自动阻断合并（附被阻断的真实提交）。
   追问预案：LLM-as-judge 怎么校准？指标怎么定阈值？

### 高频面试题清单

- 什么是 Agent？与「调一次 API 的 chatbot」本质区别？（答：循环 + 工具 + 终止条件 + 状态）
- ReAct 是什么？和 function calling 什么关系？
- MCP 协议解决什么问题？tools/resources/prompts 三类原语？
- 你的框架怎么防 Prompt 注入？多层防御讲三层以上。
- 怎么评测一个 Agent 的好坏？指标与门禁设计。
- 多轮上下文爆炸怎么办？短期/长期记忆方案。

## 项目三：简历智能分析系统（多 Agents 协同）

### 亮点候选

1. **跨语言多服务架构**：按能力特性选型——Python 解析（生态）、Java 算分（规则引擎）、Go 匹配（并发），schema 契约生成三端类型杜绝字段漂移。
   追问预案：为什么不用一种语言？契约同步怎么在 CI 保证？
2. **可解释评分**：配置化规则引擎 + 每维度 Evidence 引用评分标准原文 + 标准库版本化，报告「每个分数有出处」。
   追问预案：标准更新历史报告为什么不变？无据出分怎么被阻止？
3. **多 Agent 编排**：四 Agent DAG + 结构化状态传递 + 失败断点续跑 + 人工确认点；故障注入下系统降级明确不静默。
   追问预案：状态机怎么设计？幂等怎么保证？
4. **端到端交付**：compose 一键六组件 + Trace 全链路 + 回归集一致率 100%，clone 到 demo ≤ 15 分钟。

### 高频面试题清单

- 系统架构画一下，为什么这样拆服务？
- 三个服务之间怎么通信？失败传播怎么处理？
- 向量召回 + 规则精排两层各自解决什么？
- 如果评分被业务方质疑，你怎么自证？
- QPS 100 倍怎么扩？哪个组件先到瓶颈（答：嵌入与向量检索，讲清理由）。
