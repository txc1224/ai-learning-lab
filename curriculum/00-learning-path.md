# 学习路线：24 周从全栈工程师到 AI 全栈 / Agent 开发者

> 对应课程图主线：**从传统全栈出发，最终独立落地 Agent 项目**。
> 每周节奏假设：工作日每天 1.5～2 小时 + 周末一个 4 小时整块。忙则按 1.5 倍时间拉长，顺序不变。

## 0. 入学自测（第 0 周，不达标先补）

开始前请逐条自测，全部为「能」才建议按标准节奏走：

- [ ] 能用 TypeScript 写泛型、类型收窄、`async/await` 并处理错误（对应 `lessons/01`）。
- [ ] 能解释 HTTP 请求从进入到返回经过哪些层（对应 `lessons/00-roadmap`）。
- [ ] 能用 Git 分支协作，能读懂 `package.json` 的 scripts / dependencies。
- [ ] 能写出基本 SQL（CRUD + join），理解索引的作用。
- [ ] 至少用过一种前端框架（Vue / React）写过页面并调过接口。

不达标的项：先学 `lessons/00～03` 再回来，这部分大约额外 2～4 周。

## 2. 各阶段验收标准

### Part 1 验收（第 6 周末）：具备完整的全栈项目开发与交付能力

- [ ] 从空目录 30 分钟内搭出带分层、错误处理、日志、健康检查的 Koa 服务。
- [ ] 能解释 Webpack 从入口到产物经历了什么；能定位并优化一个慢构建。
- [ ] 能把一个业务需求画成分层架构图，并说明聚合边界。
- [ ] 组件库能按需引入、主题可换、文档可查。
- [ ] 发过一个带 CHANGELOG 的 npm 包，且业务里引用的是发包版本而非源码路径。
- [ ] `docker build && docker run` 一条命令起服务；CI 从 lint→test→build→deploy 全绿。
- [ ] **红线**：任何一站没过，不进入 Part 2。

### Part 2 验收（第 10 周末）：学会 AI Coding，与 AI 在工程规范下协作

- [ ] 能说出 AI Coding 的三个失败模式（上下文缺失、无规格生成、无评审合并）及对策。
- [ ] 有一份自己沉淀的 SDD 规格模板，并至少用它在 3 个功能上走完「规格 → 生成 → 契约测试 → 合并」。
- [ ] Koa2 → NestJS 迁移采用绞杀者模式：新旧路由共存期间接口行为一致（有对比测试）。
- [ ] Vite 迁移后产物体积、构建时间有前后数据对比。
- [ ] **红线**：AI 生成的代码必须有人的评审记录；不允许「能跑就合」。

### Part 3 验收（第 18 周末）：掌握 AI 应用开发原理，构建可用 Agent 开发框架

- [ ] 能白板画出 Agent Loop 状态机并写出伪代码（含最大步数、终止条件、异常路径）。
- [ ] LLM Gateway 支持至少 2 个 Provider 切换 + 超时重试 + 降级，且有故障演练记录。
- [ ] 工具调用有 JSON Schema 校验、白名单鉴权；未授权工具在测试中被证明不可达。
- [ ] SSE 流式含心跳、事件类型、断线恢复；Trace 能完整回放一次多步会话。
- [ ] RAG 回答带引用来源；Memory 分短期/长期且可清理。
- [ ] 改 Prompt / 换模型必须跑评测集，指标劣化即阻断合并（CI 中真实生效）。
- [ ] 可参考实现：`lessons/04～10、12～14` 的代码与本讲义互相印证。

### Part 4 验收（第 24 周末）：真实落地多 Agents 协同场景

- [ ] `docker compose up` 一条命令拉起：前端、API、三个语言 MCP 服务、Qdrant。
- [ ] 上传一份简历 PDF，端到端产出：结构化解析 → 可解释评分 → 岗位匹配 → 带引用的分析报告。
- [ ] 任一 MCP 服务宕机，系统给出明确错误而非静默错误数据（可演示）。
- [ ] Trace 面板能看到每个 Agent 步骤的输入/输出/耗时/token。
- [ ] 评分结果可解释：每项分数能追到评分标准和检索引用。

## 4. 学习纪律

1. **每周日复盘**：更新本文件勾选状态，写 `review.md`；连续两周无产出 = 节奏出了问题，砍范围不砍验收。
2. **验收驱动**：只认「能独立重写 + 能讲清楚 + 有测试」，不认「看过」。
3. **真实优先**：默认可在 mock 下学习（沿用仓库约定：`LLM_PROVIDER=mock` 等），但毕业前至少完成一次真实模型 + 真实向量库的端到端。
4. **复用优先**：已有 `lessons/` 参考实现的不另起炉灶，先读懂再改造。
5. **面试材料随周沉淀**：每完成一站就更新 `99-interview-highlights.md` 对应条目，不要毕业前突击。
