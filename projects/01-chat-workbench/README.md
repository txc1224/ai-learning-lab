# 项目 01：AI 对话工作台

## 目标

构建一个可持久化、可流式输出、可重试的 AI 对话应用。

## 当前进度

- [x] Monorepo 和前后端骨架
- [x] API 健康检查
- [x] Web 学习首页
- [ ] 会话数据模型
- [ ] 模型 Provider 抽象
- [ ] SSE 流式响应
- [ ] 消息重试和中断
- [ ] 登录与权限
- [ ] Token 和费用统计

## 技术约束

- 先使用 mock provider 验证交互和接口，不伪造真实模型结果。
- 接入真实模型前，先明确 API Key、模型名、超时和错误契约。
- 普通场景不引入 Agent ID 或硬编码业务数据。

## 验收标准

1. 用户可以创建和切换会话。
2. 用户可以看到流式生成过程。
3. 生成失败时可以重试，不会重复创建消息。
4. 用户可以中断长响应。
5. 刷新页面后历史消息仍然存在。
