# 延伸阅读笔记

本目录收录外部专栏文章的蒸馏笔记。原文链接在各篇开头，笔记只保留概念、结论和工程要点，细节请读原文。

## 专栏一：《走进 AI Agent》系列（老王以为，4 篇）

```text
第一篇：Agent 总览（是什么、怎么运转）
→ 第二篇：上下文工程（能力上限的关键）
→ 第三篇：用户记忆（跨会话记住用户）
→ 第四篇：RAG 基础（领域知识怎么进来）
```

| 篇目 | 主题 | 与仓库课程的对应 |
|---|---|---|
| [01 Agent 总览](./01-agent-overview.md) | Agent = 决策引擎 + 信息视野 + 执行通道；ReAct 循环；Harness 工程；安全护栏 | 第 0、4、7、14 课 |
| [02 上下文工程](./02-context-engineering.md) | 上下文构成、KV Cache、提示工程、状态栏、压缩与隔离 | 第 4、5、10 课 |
| [03 用户记忆](./03-agent-memory.md) | 记忆层次、存储格式、框架案例、隐私保护 | 第 3、12、15 课 |

## 专栏二：《从前端到全栈：Spring Boot 项目实战通关》（swipe，16 篇）

面向前端工程师的 Spring Boot 实战系列，补传统全栈后端能力，与 AI 课程互补。

- [专栏索引与 16 篇清单](./spring-boot-mall/README.md)
- 核心主题：工程结构、请求响应、MySQL 持久化、ORM、JWT 鉴权、Redis 缓存、状态机、并发库存、事务下单、支付回调幂等、Cache Aside、后端排错
- 与课程映射：事务/持久化 → 第 3 课；鉴权 → 第 15 课；状态机/幂等 → 第 10、14 课；缓存/排错 → 第 8、16 课

## 使用方式

1. 学完对应课程后再读笔记，效果最好：例如读完第 14 课再读 AI Agent 第一篇的 ReAct 部分。
2. 每篇笔记末尾有「行动清单」，可以转化为课程练习。
3. 笔记中的观点与课程边界一致：默认本地 mock 可验证，真实模型能力单独 smoke test。
