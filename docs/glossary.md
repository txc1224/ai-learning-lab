# AI 全栈术语表

- **Token**：模型处理文本时使用的基本片段，会影响上下文长度和费用。
- **Context Window**：一次请求中模型可见的全部内容容量。
- **Streaming**：模型边生成边返回内容，常通过 SSE 传输。
- **Embedding**：把文本转换为向量，用于语义检索。
- **RAG**：先检索外部知识，再把结果交给模型生成答案。
- **Tool Calling**：模型输出结构化工具调用请求，由程序执行工具。
- **Agent**：以模型决策为核心、由程序约束和执行的任务流程。
- **Prompt**：发送给模型的指令、背景、约束和示例。
