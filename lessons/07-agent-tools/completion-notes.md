# 第 7 课完成笔记：Agent 与工具

## 1. Agent 和普通函数调用有什么区别？

普通函数由程序固定调用；Agent 允许根据状态和输入选择下一步，但每一步仍必须由程序约束。

## 2. 为什么要有 ToolRegistry？

白名单注册表让系统只执行显式允许的工具，避免模型或用户传入任意函数名。

## 3. 为什么工具执行前要校验参数？

参数来自不可信输入。校验失败时不能产生副作用，应返回 failed 状态。

## 4. 最大步数解决什么问题？

Agent 可能不断重复决策。`maxSteps` 是硬边界，防止无限循环、费用和资源失控。

## 5. 什么时候需要人工确认？

删除、支付、发送消息、修改生产数据等有副作用的操作必须暂停，让人确认后再执行。

## 6. 本课如何连接 RAG 和 SSE？

RAG 可以作为一个受控检索工具；Agent 每一步可以通过 SSE 推送状态。当前只实现本地 calculator，避免外部副作用。

## 已验证与边界

本地工具注册、参数校验、状态迁移、最大步数逻辑可验证；真实 LLM 自主工具选择和第三方系统副作用未验证。

## 记忆卡片
