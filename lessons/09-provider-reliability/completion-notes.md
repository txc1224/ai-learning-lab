# 第 9 课完成笔记

## 本课解决什么

模型文本是不可信输入。程序必须解析、校验、分类错误，再决定是否重试。

## 代码链路

```text
模型文本 → extractJson → JSON.parse → isAnswer → 业务使用
```

Provider 错误通过 `retryable` 标识是否可重试；配置和权限错误不应无限重试。

## 与工作台的关系

第 4 课已经有 Provider 抽象，本课补齐输出和可靠性边界，为后续流式、RAG 和 Agent 提供可信失败模型。

## 已验证

结构化输出工具和重试策略可在本地 mock 中运行。真实供应商 usage、上游协议和模型质量需要可选 smoke test。

## 不发散

不进入模型训练、评测平台或复杂 JSON Schema 框架。

## 记忆卡片

```text
解析不等于校验
校验不等于业务正确
retryable 不等于永远重试
```
