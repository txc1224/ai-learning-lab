# 第 11 课代码地图

| 能力 | 文件 | 重点 |
|---|---|---|
| API 封装 | `apps/web/src/api-client.ts` | 会话和 stream 请求 |
| React 状态 | `apps/web/src/main.tsx` | current/loading/error/controller |
| 消息追加 | `handleSend` | optimistic user/assistant |
| 停止 | AbortController | 取消 fetch |
| UI | `apps/web/src/style.css` | 会话、消息、输入区 |

本课优先学习状态流转，不引入复杂状态管理库。
